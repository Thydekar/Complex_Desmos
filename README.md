# Complex Desmos

The best free 3D complex function plotter in the world.

Live app URL: https://complex-desmos.streamlit.app

Works with any function: polynomials, exp, log, sin, gamma, zeta, etc.  
Shows Re(f), Im(f), exact zeros, real/imaginary axes, and more.
